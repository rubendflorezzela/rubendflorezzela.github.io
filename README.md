# Ruben Dario Florez-Zela · Academic Website

Personal academic website of **Ruben Dario Florez-Zela**, focused on **Human-Centered AI for Intelligent Transportation Systems**, trustworthy and deployable AI, driver monitoring, computer vision, and intelligent vehicle systems.

**Live site:** https://rubendflorezzela.github.io/

## Website sections

- **About** — research profile, current directions, selected outputs, and recent activity.
- **Publications** — journal articles, conference papers, and preprints.
- **Projects** — current research, published systems, and open-source technical projects.
- **Teaching** — university teaching experience.
- **CV** — academic background, research experience, reviewing activity, and professional information.

## Contact

For research collaboration or academic inquiries, see the contact links available on the website.


## Theme assets

The site supports Dark, Light, and System themes. The dark theme uses `assets/images/profile.jpg`; to enable the color portrait in the light theme, add the matching color photograph as `assets/images/profile-color.jpg`. If that file is unavailable, the site safely falls back to the current portrait.

## Search visibility

The site includes canonical URLs, crawl directives, a sitemap, and structured profile data. After meaningful updates, submit `sitemap.xml` in Google Search Console and use URL Inspection on the home page when a recrawl is important.
